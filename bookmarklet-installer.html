🏍️ Motorradfreunde Filebase Downloader

Lade die komplette Filebase mit allen Metadaten als SQLite-Datenbank herunter

📚 Was ist ein Bookmarklet?

Ein Bookmarklet ist ein Lesezeichen mit JavaScript-Code statt einer URL. Wenn Sie darauf klicken, wird der Code auf der aktuell geöffneten Webseite ausgeführt. Das ermöglicht zusätzliche Funktionen ohne Installation von Software oder Browser-Erweiterungen.

✨ Features

📦 Kompletter Download - Lädt alle Dateien aus der Filebase mit Metadaten
🗄️ SQLite-Format - Speichert alle Daten in einer SQLite-Datenbank
📊 Vollständige Metadaten - Titel, Beschreibung, Kategorie, Uploader, Datum, Größe, Download-Count
🔄 Automatische Paginierung - Durchsucht automatisch alle Seiten
📈 Live-Progress - Zeigt Fortschritt in Echtzeit
🔒 Sicher & Lokal - Läuft komplett im Browser, keine Daten verlassen den PC

Ziehe den blauen Button oben in deine Lesezeichen-Leiste. Alternativ: Rechtsklick auf den Button → "Als Lesezeichen hinzufügen"

Der Downloader scannt alle Seiten der Filebase und erstellt eine SQLite-Datenbank. Diese wird automatisch heruntergeladen.

💾 Was wird gespeichert?

Die SQLite-Datenbank enthält folgende Tabellen:

Tabelle: files

  • id - Eindeutige ID
  • title - Dateititel
  • filename - Dateiname
  • description - Beschreibung
  • category - Kategorie
  • upload_date - Upload-Datum
  • uploader - Hochgeladen von
  • file_size - Dateigröße in Bytes
  • download_count - Anzahl Downloads
  • download_url - Download-Link
  • page_url - Link zur Detailseite
  • file_id - Interne File-ID
  • metadata - Zusätzliche Metadaten als JSON

Tabelle: categories

  • id - Eindeutige ID
  • name - Kategoriename
  • file_count - Anzahl Dateien

Tabelle: metadata

  • key - Metadaten-Schlüssel
  • value - Metadaten-Wert

🔍 SQLite-Datenbank öffnen

Du kannst die heruntergeladene .sqlite-Datei mit verschiedenen Tools öffnen:

Desktop-Programme:

  • DB Browser for SQLite - sqlitebrowser.org (kostenlos, Windows/Mac/Linux)
  • DBeaver - dbeaver.io (kostenlos, universal)
  • SQLiteStudio - sqlitestudio.pl (kostenlos)

Online-Tools:

  • SQLite Viewer - inloop.github.io/sqlite-viewer

Programmier-Sprachen:

# Python import sqlite3 conn = sqlite3.connect('motorradfreunde-filebase-2026-01-18.sqlite') cursor = conn.cursor() cursor.execute('SELECT * FROM files') for row in cursor.fetchall(): print(row)

❓ Troubleshooting

Bookmarklet funktioniert nicht

  • Stelle sicher, dass du auf motorradfreunde-rheinneckar.de eingeloggt bist
  • Lade die Seite neu und versuche es erneut
  • Prüfe in der Browser-Console (F12) auf Fehlermeldungen

Download wird nicht gestartet

  • Erlaube Pop-ups und Downloads für motorradfreunde-rheinneckar.de
  • Prüfe, ob dein Browser Downloads blockiert

Keine Dateien gefunden

  • Stelle sicher, dass du Zugriff auf die Filebase hast
  • Öffne manuell die Filebase und prüfe, ob Dateien sichtbar sind
  • Das HTML-Layout könnte sich geändert haben - kontaktiere den Entwickler
